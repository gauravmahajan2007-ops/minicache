Block Lifecycle

Every block in the pool is in exactly one of three states. A block is never evicted while active (in-flight); when released it becomes reusable and carries a priority + optional duration-TTL that governs eviction under memory pressure.

invalidate force-frees a block from any state and is idempotent. Eviction order is prioritized-LRU: lowest effective priority first (priority reverts to the default 35 once its duration expires), then least-recently-used within a tier.
